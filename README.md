# АстраханьМастер MVP

## Что сделано
- Public landing page на русском
- Категории и лендинги `/uslugi/[slug]`
- Форма заявки с маской телефона и успешным сообщением
- Prisma-схема для `User`, `Master`, `Category`, `Subcategory`, `Lead`, `Transaction`, `Review`
- Seed с 4 категориями, 10 подкатегориями, 3 мастерами и 20 заявками
- Sitemap и robots.txt для индексации

## Запуск
1. Создайте файл `.env` по примеру `.env.example`
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Выполните миграции и seed:
   ```bash
   npx prisma migrate dev --name init
   npm run prisma:seed
   ```
4. Запустите проект:
   ```bash
   npm run dev
   ```

Открыть: http://localhost:3000

## Vercel + Supabase
1. Создайте базу PostgreSQL в Supabase
2. Подключите репозиторий в Vercel
3. Добавьте переменные окружения: `DATABASE_URL`, `NEXT_PUBLIC_APP_URL`, `SESSION_SECRET`
4. Запустите деплой
